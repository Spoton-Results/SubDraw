Migrate all file uploads from local Replit storage to Cloudflare R2. The following environment variables are now set in Replit Secrets and ready to use: CLOUDFLARE_R2_ACCOUNT_ID, CLOUDFLARE_R2_ACCESS_KEY_ID, CLOUDFLARE_R2_SECRET_ACCESS_KEY, CLOUDFLARE_R2_BUCKET_NAME, CLOUDFLARE_R2_ENDPOINT.
STEP 1 — Install the AWS S3 SDK which is compatible with Cloudflare R2. Run: npm install @aws-sdk/client-s3 @aws-sdk/s3-request-presigner
STEP 2 — Create a utility file at src/lib/r2.ts or src/utils/r2.ts with the following:
Import S3Client, PutObjectCommand, GetObjectCommand, and DeleteObjectCommand from @aws-sdk/client-s3. Import getSignedUrl from @aws-sdk/s3-request-presigner.
Create and export an S3Client configured with: region set to auto, endpoint set to process.env.CLOUDFLARE_R2_ENDPOINT, credentials using process.env.CLOUDFLARE_R2_ACCESS_KEY_ID and process.env.CLOUDFLARE_R2_SECRET_ACCESS_KEY.
Create and export an uploadToR2 function that accepts a file buffer, a filename string, a content type string, and a folder string. The function should generate a unique key using the folder plus a timestamp plus the original filename — for example plans/1711234567890-architectural-plans.pdf. Upload the file to the bucket using PutObjectCommand with the bucket name from process.env.CLOUDFLARE_R2_BUCKET_NAME. Return the full public URL of the uploaded file formatted as: process.env.CLOUDFLARE_R2_ENDPOINT + / + process.env.CLOUDFLARE_R2_BUCKET_NAME + / + key.
Create and export a deleteFromR2 function that accepts a file key and deletes it from the bucket using DeleteObjectCommand.
Use these folder names to organize files: plans, scope-docs, insurance, licenses, contracts, signed-contracts, compliance, submittals, invoices, lien-waivers, avatars.
STEP 3 — Find every file upload handler in the entire codebase. This includes but is not limited to: plan file uploads on the project page, scope document uploads, GC insurance certificate uploads, GC license document uploads, sub insurance certificate uploads, sub license document uploads, subcontract agreement uploads by GC, signed contract uploads by sub, compliance checklist document uploads, submittal document uploads by GC and sub, and any other place where a file is saved to local storage or a local path is stored in the database.
