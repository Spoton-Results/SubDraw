PART 3 — CREATE ACCOUNT API ROUTE:
Create POST route at /api/stripe/connect/create-account. This route must verify the user is authenticated and is a subcontractor account. Do the following:
Check if the sub already has a stripeConnectAccountId in the database. If yes skip account creation and go directly to generating a new account link.
If no account exists use the Stripe v2 API to create a new Express account. Use the StripeClient with your STRIPE_SECRET_KEY. Call client.v2.core.accounts.create with the following parameters: contact_email set to the sub's email address, display_name set to the sub's company name, dashboard set to express, identity set with country us and entity_type individual for sole proprietors, configuration set with merchant capabilities card_payments requested true, defaults set with currency usd and locales en-US.
Store the returned account ID as stripeConnectAccountId in the database and set paymentAccountStatus to PENDING.
Then create an account link using client.v2.core.account_links.create with account set to the new account ID, use_case type set to account_onboarding, account_onboarding set with return_url pointing to the app URL plus /account/payment-success, refresh_url pointing to the app URL plus /account/payment-setup, collection_options fields set to eventually_due, and configurations set to merchant.
Return the account link URL to the frontend. The frontend immediately redirects the sub to that URL. This is the Stripe hosted onboarding page branded with SubTracker name and colors as configured in the Stripe Connect dashboard settings.
